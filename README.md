# PALMEIRAS - projeto front-end

Este projeto vem a entender o bom uso de Html e Css
sobre as paginas web e bom uso de programação

## Oque foi feito

-Criaçaõ de estrutura de HTML em pagina
-Organização de conteúdo em seções
-'herdar','nav','main','section','article' e 'table'
-Colocamos banner
-Fizemos estilização de Css
-Definimos cores, fontes, espaçamentos e layout visual

## Estrutura do projeto 

-'index.html' - estrutura da pagina
-'style.css' - estilo e layout do site
-'imagem/' - imagens usadas do projeto

## tecnologia utilizadas

- HTML
